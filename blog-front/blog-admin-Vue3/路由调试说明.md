## 需要检查的问题

### 404 问题可能的原因

1. **后端返回的 component 路径格式不匹配**
   - 后端可能返回: `/home/Home.vue` 或 `home/Home` 或其他格式
   - `loadView` 的 `pathMap` 映射需要匹配后端实际格式

2. **Vue3 组件文件不存在**
   - 映射的目标组件文件可能还未创建
   - 例如: `blog/home/index.vue` 不存在会导致 404

## 调试步骤

1. **打开浏览器控制台**
2. **刷新页面，重新登录**
3. **查看控制台输出**，应该看到：
   ```
   原始菜单数据: [...]
   侧边栏路由: [...]
   路由 xxx: { component: ..., children: [...] }
   ```

4. **找出 404 的路由**，检查：
   - 后端返回的 `component` 字段值是什么？
   - `pathMap` 中有没有对应的映射？
   - 映射后的文件 `src/views/blog/xxx/index.vue` 是否存在？
