## 🚀 快速启动

### 环境要求
- Node.js >= 16.0.0
- npm >= 8.0.0 或 pnpm

### 启动步骤

```bash
# 1. 进入项目目录
cd D:\桌面\blog-master\blog-satoken\blog-front\blog-admin-Vue3

# 2. 安装依赖 (如果还没安装)
npm install

# 3. 启动开发服务器
npm run dev

# 4. 浏览器访问
# http://localhost:80 或 http://localhost:3000 (如修改了端口)
```

### 注意事项
⚠️ **端口 80 需要管理员权限**,建议修改为 3000:
```javascript
// vite.config.js 第 45 行
server: {
  port: 3000,  // 修改为 3000
}
```

⚠️ **后端服务依赖**: 需要启动后端服务在 `http://localhost:8080`
