# 博客后台管理系统 - 冗余功能清理清单

## 项目分析概述

本项目基于若依（RuoYi）管理系统模板改造，包含大量若依框架自带的企业级管理功能。
对于博客系统来说，许多功能是不必要的。

### 博客实际需要的核心功能模块

✅ **保留的博客核心功能**：
- 文章管理（Article）
- 分类管理（Category）
- 标签管理（Tag）
- 评论管理（Comment）
- 留言管理（Message）
- 说说管理（Talk）
- 相册管理（Album）
- 友链管理（FriendLink）
- 用户管理（User）
- 角色管理（Role）
- 菜单管理（Menu）
- 资源管理（Resource）
- 页面管理（Page）
- 关于页面（About）
- 网站配置（Website/Setting）
- 操作日志（Operation Log - 博客自己的）
- 首页统计（Home）
- 在线用户（Online - 博客自己的）
- 系统公告（Notice - 博客自己的）
- 表白墙（Love）

## 四、删除操作清单

### 阶段一：删除监控模块（安全性高）

```bash
# 删除监控相关页面
rm -rf src/views/monitor/

# 删除监控相关API
rm -rf src/api/monitor/
```

### 阶段二：删除工具模块（安全性高）

```bash
# 删除工具相关页面
rm -rf src/views/tool/

# 删除工具相关API
rm -f src/api/tool/gen.js
```

### 阶段三：删除系统管理模块（需谨慎）

**3.1 删除字典管理**
```bash
# 删除字典页面
rm -rf src/views/system/dict/

# 删除字典API
rm -rf src/api/system/dict/

# 删除字典Store（检查后删除）
rm -f src/store/modules/dict.js

# 检查并删除字典工具（如果未被使用）
# rm -f src/utils/dict.js
```

**注意**：删除前需要检查以下文件中的引用并手动清理：
- `src/main.js`：可能有 `dict` 工具的全局注册
- `src/utils/dict.js`：检查是否被其他模块使用
- `src/views/tool/gen/editTable.vue`：引用了字典API（工具模块会一起删除）

**3.2 删除参数设置**
```bash
rm -f src/views/system/config/index.vue
rm -f src/api/system/config.js
```

**注意**：检查 `src/main.js` 中是否有 `getConfigKey` 引用

**3.3 删除部门和岗位**
```bash
rm -f src/views/system/dept/index.vue
rm -f src/api/system/dept.js
rm -f src/views/system/post/index.vue
```

**3.4 删除若依通知公告**


**3.5 删除若依菜单管理**

```bash
rm -f src/views/system/menu/index.vue
```

**3.6 删除若依角色管理**

```bash
rm -rf src/views/system/

```

### 阶段四：清理路由配置

编辑 `src/router/index.js`，删除 `dynamicRoutes` 数组中的所有内容（第101-172行）：

```javascript
// 动态路由，基于用户权限动态去加载
export const dynamicRoutes = [
  // 全部删除，因为：
  // 1. 用户授权、角色授权路由 -> 若依功能，博客不需要
  // 2. 字典数据路由 -> 字典功能已删除
  // 3. 定时任务日志路由 -> 监控功能已删除
  // 4. 代码生成器路由 -> 工具功能已删除
]
```

改为：

```javascript
// 动态路由，基于用户权限动态去加载
export const dynamicRoutes = []
```

### 阶段五：清理依赖引用

**5.1 检查并修改 `src/main.js`**

删除字典相关引用：
```javascript
// 删除这些行（如果存在）
import { getDicts } from "@/api/system/dict/data"
import { getConfigKey } from "@/api/system/config"
import { parseTime, resetForm, addDateRange, selectDictLabel, selectDictLabels, download, handleTree } from "@/utils/ruoyi"

// 删除字典相关的全局方法注册
app.config.globalProperties.getDicts = getDicts
app.config.globalProperties.getConfigKey = getConfigKey
```

**5.2 检查 `src/utils/dict.js`**

如果该文件仅被若依系统模块使用，则删除：
```bash
rm -f src/utils/dict.js
```

**5.3 检查 `src/utils/ruoyi.js`**

保留该文件，但检查是否有字典相关的工具函数，如 `selectDictLabel`、`selectDictLabels` 等，如果博客没有使用可以删除这些函数。

## 七、注意事项

### 7.1 备份

删除前请务必：
1. **提交当前代码到 Git**
2. **创建新分支进行清理工作**
3. **做好数据备份**

```bash
git checkout -b feature/cleanup-ruoyi-modules
git add .
git commit -m "backup: 清理若依冗余模块前的备份"
```

### 7.2 分阶段删除

建议按照以下顺序逐步删除，每阶段都测试编译和运行：

1. ✅ 第一阶段：删除监控模块（最安全）
2. ✅ 第二阶段：删除工具模块（很安全）
3. ⚠️ 第三阶段：删除系统管理模块（需谨慎）
4. ⚠️ 第四阶段：清理路由配置（需测试）
5. ⚠️ 第五阶段：清理依赖引用（需仔细检查）

### 7.3 可选保留

以下模块可以考虑保留：

1. **个人中心** (`src/views/system/user/profile/*`)
   - 如果博客使用这些页面，且已对接博客API，可以保留
   - 建议移动到 `src/views/user/profile/` 并统一使用博客API

2. **字典管理**
   - 如果博客有使用字典功能（如状态下拉选项配置），可以保留
   - 需检查实际使用情况

3. **登录日志**
   - 如果博客没有自己的登录日志实现，可以考虑保留若依的
