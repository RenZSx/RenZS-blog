## 🚀 快速开始（15-20分钟）

### 第一步：备份（1分钟）
```bash
git checkout -b feature/cleanup-ruoyi-modules
git add .
git commit -m "backup: 清理前的备份"
```

### 第二步：执行清理（1分钟）
```bash
# Windows
cleanup.bat

# Linux/Mac  
chmod +x cleanup.sh
./cleanup.sh
```

### 第三步：手动清理（5分钟）
1. 编辑 `src/router/index.js`，清空 `dynamicRoutes` 数组
2. 编辑 `src/main.js`，删除字典和配置相关引用
3. 检查 `src/utils/dict.js` 是否需要删除

### 第四步：测试验证（10分钟）
```bash
# 编译测试
npm run build:prod

# 运行测试
npm run dev
```

测试核心功能：登录、首页、文章管理、用户管理、权限控制

### 第五步：提交（2分钟）
```bash
git add .
git commit -m "chore: 清理若依冗余模块"
```

## ⚠️ 重要提示

### 删除前必做
1. ✅ **创建备份分支** - 确保可以随时回滚
2. ✅ **阅读清理清单** - 了解将要删除的内容
3. ✅ **确认博客功能** - 确保博客有自己的实现

### 可能的风险点
1. ⚠️ **字典功能** - 如果博客使用了字典，需要保留
2. ⚠️ **个人中心** - 检查是否调用博客API
3. ⚠️ **操作日志** - 确认博客有自己的日志实现

### 删除后必做
1. ✅ **编译测试** - 确保无编译错误
2. ✅ **功能测试** - 测试所有核心功能
3. ✅ **检查控制台** - 无错误和404

---

## 📝 操作建议

### 建议按此顺序删除（安全优先）
1. **监控模块** - 最安全，博客肯定不需要
2. **工具模块** - 很安全，开发工具，非运行时功能  
3. **系统管理模块** - 需谨慎，确认博客有自己的实现
4. **路由配置** - 删除后需测试
5. **依赖引用** - 需仔细检查

### 可选保留项
- 个人中心页面（如果博客使用且已对接博客API）
- 字典管理（如果博客有使用字典功能）
- 登录日志（如果博客没有自己的实现）

## 📞 常见问题

### Q: 删除后编译报错？
**A:** 说明还有文件引用了已删除的模块，使用 `grep -r` 搜索并删除引用

### Q: 删除后页面空白？
**A:** 检查浏览器控制台，通常是路由配置问题

### Q: 想保留某些功能？
**A:** 在脚本中注释掉对应的删除命令

### Q: 打包体积没变化？
**A:** 重新 `npm install`，并使用 `npm run build:prod --report` 查看分析
